# Agent 轨迹采集口径

2026-10-19 用户明确：所有负载在录制阶段均不考虑最终答案或修复结果是否正确，只要求任务运行完成。后续系统实验以完成任务数、完成吞吐、端到端时延和资源开销为主要指标，不以答案正确率或正确完成吞吐作为当前优化目标。

录制入库不按金标准答案、测试通过率、最终补丁正确性或支持句正确性筛选。任务做错但正常结束，仍保留完整轨迹；已有错误答案轨迹不删除，也不为追求正确答案重录。新问答适配器默认关闭答案评分，只有显式 `--score-answers` 才产生辅助诊断，评分不影响资格。

“运行完成”与“答案正确”分开：模型调用正常结束、工具调用收尾、轨迹和观测完整。超时、模型调用预算耗尽、接口故障、未收尾后台任务或录制丢失单独记录为未完成或证据不完整，不能通过忽略这些异常凑完成数。

离线实验仍验证模型请求、真实工具输入输出和文件副作用与录制一致，禁止用缓存工具结果掩盖实际执行偏离。该检查是实验一致性检查，不是答案正确性判断。历史软件任务中的独立测试结果可作为一致性辅助证据留存；测试是否通过本身不决定是否录制、入库或纳入并发集合。

所有失败与未完成尝试保留，说明无法回放的比例及原因。报告完成吞吐时纳入所有提交任务，超时、异常退出单列；有限批次完成数/时间不冒充稳态吞吐。

该规则适用于现有代码轨迹和后续检索、网页、代码生成等全部负载。历史报告中的正确数是旧诊断，不用于后续筛选；历史数据不回写成新口径下的“成功”。
